# Four In Line - Frontend Application

This is the React frontend application for Assignment 3, designed to connect directly to the REST API built in Assignment 2.

## Installation Instructions
To install the required dependencies for this React application, open your terminal, navigate to the root directory of this frontend project, and run the following command:

```bash
npm install
```

## Start Instructions
To start the Application run the following command:

```bash
npm start
```

## API Base URL: 
http://localhost:3000

The documentation for the server is in Server/docs/README.MD
