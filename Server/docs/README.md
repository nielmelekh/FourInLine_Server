# FourInLine Server

## How to run the server
Open the cmd, navigate to the root folder, then follow the next steps

## Install dependencies:
run: "npm install express"

## Start the server:
run: "npm start"  \
Now the server is listening on port 3000.

## Access the server:
Access it through the URL http://localhost:3000/  \
The api's base path is /  \
Check the ApiReference for available endpoints

## Assumptions
The indexes of users and matches start at 1.
